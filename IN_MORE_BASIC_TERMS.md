# In More Basic Terms

Imagine several routes through a city. The route people use most often might be the shortest. It might also be the one with the most entrances, the fewest roadblocks, or the clearest signs. Counting travelers tells us what happened. It does not automatically tell us why.

Evolution has a similar problem. A mutation can be common because it happens often, because the organism can tolerate it, because it helps the organism reproduce, or because our experiment makes it easier to detect. TMD asks whether we can turn those possibilities into reliable predictions about evolutionary routes.

That is a useful question. Answering it means doing more than finding a curve that matches old results.

## What we improved

We checked where the old numbers came from. One set compared mutations from different engineered bacterial strains. Treating those samples as competitors in the same race would give the numbers a meaning the experiment never measured. We corrected that interpretation. Some repeated files were also copies of the same evidence, and earlier timing examples were simulations.

We then returned to a published study of antibiotic-resistant bacteria. Its table records mutations from two growth media and three experimental blocks. Restoring those blocks let us train a simple prediction on two blocks and test it on the third. Predictions that used the growth medium did better in all three tests. That supports the practical idea that conditions matter in this dataset. The original researchers had already reported differences between the media; our contribution is a clearer, repeatable secondary analysis.

## A new question we can test

Do early mutations use the same routes as late mutations?

We built a tool to test that question using independent replicate experiments. It also accounts for experiments that end before a mutation is observed. We tested the tool on made-up data whose answers we knew in advance. It behaved reasonably in those selected tests and detected a deliberately strong change in route use over time. Real biology still needs real measurements.

Different environments must be compared carefully. If one environment produces faster events and favors route A while another is slower and favors route B, mixing them can make time appear to change route choice even when it does not within either environment.

## What the mathematics tells us

Sometimes several different explanations produce exactly the same observable pattern. We derived three different ways to produce the same waiting-time curve and route shares. Seeing that pattern would not tell us which explanation is right.

This is valuable because it tells us what to measure next. We need independent information about how often mutations arise, how their effects differ, and how the experiment detects them. Those measurements help separate explanations that otherwise look identical.

## What would count as stronger evidence?

Write down the prediction before seeing the new results. Measure mutation supply under the same conditions. Keep experimental blocks and independent cultures identifiable. Test an entirely new condition without adjusting the prediction afterward. Compare TMD with strong existing explanations, including known mutation hotspots and differences in fitness.

A successful prediction could strengthen the hypothesis. A failed prediction could reveal which assumption needs changing. Either result is more useful than calling a promising idea proven before the evidence is ready.
