# Mutation by Natural Dominance — Can founder fitness predict which competitor finishes ahead?

Published 20 November 2026 in the Mutation by Natural Dominance report and methods series as version 0.12.0. In 76 yeast competitions, adding a fitness measurement to the starting shares reduced the number of correct day-25 leader predictions from 45 to 40. In the same 21 standard diploid wells, starting share alone predicted 11 leaders, the combined rule using the main assay predicted 12, and using a second stock assay gave 16. In independent green-algae trials, monoculture growth rates often identified the final leader, but projecting those rates increased the average error in final share.
