# Khristich founder assignment and transfer coverage

**The frozen transfer test is unscored.** The revised study reports a shared starting pool of 282 natural yeast founders across 20 biological populations per condition. A separate laboratory reference series was added in replicate-specific combinations. Author Supplementary Table 3 is a barcode reference with 388 records and 371 distinct labels on its first sheet. Its columns give the strain ID and consensus barcode. Its second sheet contains 67 review records. Both sheets have duplicate-value formatting and zero hidden rows. Neither provides the complete post-exclusion mapping to the 282 founders. The methods describe excluding duplicate barcodes, failed growth after thawing, haploids, flocculating isolates and killer strains. Membership is necessary for the per-population denominators, change factors and eligible endpoint comparison. [Study revision](https://doi.org/10.1101/2025.10.09.681448) · [Supplementary materials](https://www.biorxiv.org/content/10.1101/2025.10.09.681448v2.supplementary-material)

All 20 plain-M3 populations have records at transfers 0, 2 and 63. Across the three visits, 18,234 source rows become 13,046 population-by-visit-by-label cells after technical pooling. The baseline union contains 327 observed labels, of which 10 appear in every population. The per-population baseline ranges from 12 to 320 recorded labels. Thirteen populations have multiple sample IDs at baseline, fifteen at transfer 2, and zero at transfer 63. Baseline secondary-primer plates are C for R1–R10 and B for R11–R20. Both halves use B at transfer 2 and D at transfer 63. The two halves share the original natural founder stock. Occurrence lists and label spelling alone cannot establish which natural founders were assigned. The JSON reports exact-match coverage and counts under source-spelled unknown, uncertain and laboratory-reference labels. These descriptive categories cannot determine the total number of reads attributable to excluded founders.

The author repository has one branch. Commit 1c352209a1a611b044847281e013d505553f1a88, dated 2025-10-14, is the last commit depositing counts. The most inclusive long-term count table is 23,621,023 bytes. The bioRxiv indexing API lists v1 dated 2025-10-10 and v2 dated 2026-09-21. Its journal-publication field reads NA for both as checked on 2026-11-21. The v1 archive and v2 standalone Table 3 have byte-identical workbooks. ## Reproduce the coverage audit

Save the pinned count CSV as `khristich-counts.csv` and the native v2 Supplemental Table 3 workbook as `khristich-S3.xlsx`. The v1 supplementary ZIP also contains this workbook under `supplementary tables/Table S3. Genetic barcodes.xlsx`. Its SHA-256 digest is d27fe37b56d87e4be9a1de6e1b85f6cdd8230729cda287eeef4565400f1d7dad. The count file digest is 49bd605ffa896beed59e16eb013d65bdea8ae0a33e54ac574157dfbf277541fa. The portable Python program verifies both and emits aggregate JSON. [Pinned count CSV](https://raw.githubusercontent.com/omghosh/longterm-natties/1c352209a1a611b044847281e013d505553f1a88/data/all_bc_counts_April2025_LongTerm.csv) · [Native workbook](https://www.biorxiv.org/content/biorxiv/early/2026/09/21/2025.10.09.681448/DC2/embed/media-2.xlsx?download=true)

```sh
python3 khristich_roster.py khristich-counts.csv khristich-S3.xlsx
```

The missing source object is the final 282-member founder list with its exact count-table IDs, including any aliases and how uncertain assignments should be treated. With that mapping the already-frozen rules can be applied without revising either split or outcome.
