# Which leaf was actually measured at M101?

The 2016 leaf labelled **DHQ1_B1-1-L1** maps to BioSample **SAMN10274729**, experiment **SRX5003298**, and paired whole-genome run **SRR8183363**. The sample name and library name match the published sample identifier exactly. The nearby leaf labelled L2 has a separate run, SRR8183378. The accession crosswalk matches all 75 DHQ1 leaf names in the original S1 Data to 75 distinct BioSamples, experiments and runs in the study. The ten additions shared by both minimum tables in version 0.9.0 span six sites and seven of those runs. We reopened all seven native NCBI run records to check the individual leaf labels. [NCBI target run XML](https://www.ncbi.nlm.nih.gov/Traces/sra-db-be/run_new?acc=SRR8183363) · [NCBI experiment](https://www.ncbi.nlm.nih.gov/sra/SRX5003298) · [Study run roster](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=PRJNA497989&result=read_run&fields=run_accession,sample_accession,sample_alias,library_name,experiment_accession&format=tsv&limit=0) · [Published sample roster](https://doi.org/10.1371/journal.pbio.3000191.s018)

Wang et al. used the GDR v2.0.a1 peach genome and reported the G-to-A change at Pp04 position 21,561,355. NCBI assembly GCF_000346465.2 names Pp04 as RefSeq NC_034012.1 and GenBank CM007654.1. Both sequences report G at the study position in one-based coordinates. This checks the reference allele. The target leaf's listed mean mapped depth is 47.59 and 92.5% of its genome reached at least five reads. Neither statistic gives a count of reference or alternate bases at M101 in that leaf. ## Read evidence and the independent assay

The run contains 50,599,581 paired spots and 15,179,874,300 bases. ENA lists two FASTQ downloads totaling 8,542,472,399 compressed bytes. NCBI lists two original FASTQs and normalized SRA and SRA Lite files. Neither inventory listed a coordinate-indexed BAM or CRAM for this leaf. The ENA study analysis query returned no records. The same BioSample returned only one run in the ENA file report. On 19 November 2026, HTTP range requests for the two ENA FASTQs and NCBI’s advertised normalized and Lite run files were blocked by the analysis environment’s network proxy (HTTP 403). We did not obtain a site-specific read count. A future recount of that run would reanalyze the original leaf library. The number of observed alternate reads in a bulk sample also depends on sampling depth and the fraction of cells carrying the allele. [ENA target FASTQs](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=SRR8183363&result=read_run&fields=run_accession,sample_alias,read_count,base_count,fastq_bytes,fastq_ftp,submitted_ftp,submitted_format&format=tsv) · [ENA BioSample report](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=SAMN10274729&result=read_run&fields=study_accession,sample_accession,sample_alias,run_accession,library_name&format=tsv) · [Study analysis records](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=PRJNA497989&result=analysis&fields=analysis_accession,analysis_type,submitted_ftp&format=tsv)

The NCBI Run Browser returned metadata for a single requested sequencing spot. Its help describes a ten-million limit on run size for subsequence search. A search in this 50.6-million-spot run for the 31 reference bases centered on M101 returned HTTP 502. An individually addressable spot is not a position-indexed read, and the failed search supplied no allele evidence. [Run Browser](https://www.ncbi.nlm.nih.gov/Traces/?view=run_browser&acc=SRR8183363&display=reads) · [NCBI search help in the viewer template](https://www.ncbi.nlm.nih.gov/Traces/sra-web-fe/xsl/reads_layout.xml)

Wang et al. reported PCR and Sanger results across 89 mutations in 122 mutated samples, 59 progeny samples and 274 controls. They reported zero mutant alleles in the controls. The publication does not identify this leaf–M101 combination as one of those controls. Ji et al. subsequently used independent PCR/Sanger quantification at M101. Their Methods identify three new flowers and replicate DNA from the subtending leaf **1-1-8-7-10-L2** near Flower #2. The organ and specimen identifiers distinguish that later test from the 2016 leaf **DHQ1_B1-1-L1**. The later assay establishes that the authors measured M101 in a leaf using another method. It leaves the original target’s status unresolved. A targeted paper-index search of 15 results and the run-linked publications identified no independent genotype for the target combination. [Wang et al., Methods](https://doi.org/10.1371/journal.pbio.3000191) · [Ji et al., independent lineage quantification in Methods](https://doi.org/10.1371/journal.pgen.1011829) · [Sanger measurements](https://doi.org/10.1371/journal.pgen.1011829.s024)
