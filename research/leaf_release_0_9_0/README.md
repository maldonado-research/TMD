# Leaf carrier lists and branch distances, version 0.9.0

Published 19 November 2026 Pacific in the Mutation by Natural Dominance report and methods series. This supplement examines mutation carrier lists in one peach tree and physical and genetic branch distances in four tropical trees. The peach study used branch information in discovery. The tropical-tree study recorded physical architecture separately. The two analyses describe relative relationships among observations. The biological prediction about which route first produces a successful heritable outcome remains open.
