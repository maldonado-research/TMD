# Selection-aware thresholding: source boundary

The companion implementation also calibrates an inclusive maximum rule when
the maximum multiplicity K is recorded, using its separately proved
selection-aware CP upper bound. This does not change the source conclusion:
K is unreported and can equal n, which gives upper bound one. The assumptions
about score construction, sampling and native transport remain necessary.

The earlier source audit correctly distinguishes threshold-selection observations from independent validation of a gate fixed beforehand. Its statement that these observations do not justify a **fixed-gate** population false-positive interval should be retained. A clarification can prevent that statement being read as a blanket rejection of inference after threshold selection: order-statistic calibration can account for a specified selection rule under additional assumptions.

The cached SLST article reports twelve workflow blanks, a maximum of 50 full-length reconstructed SLST sequences, and exclusion of samples with fewer than 50 sequences (Results s2_3, paragraph 3). Its literal complementary count gate is therefore `N >= 50`. Applying that count predicate to the same blank values gives between 1 and 12 passes; all passing values must equal 50. The number of ties at 50 is unavailable. This describes the reported count predicate, not an assertion that blank records entered the clinical analysis. The score is an integer sequence count, so continuity is not established and cannot be silently assumed. Methods s4_7 identifies nuclease-free water processed through the workflow; the Supplementary Table 3 caption describes per-run blank sequences, but the table itself remains unacquired.

For a **counterfactual prospective procedure**, let a fixed score pipeline produce `n` iid calibration scores from the same population as future controls, let the sample size be fixed in advance, set `M = max_i S_i`, and freeze the strict gate `S > M` for future units. If `p_>(M) = P(S_new > M | M)`, the classical one-sided order-statistic tolerance bound gives

`P_calibration{p_>(M) > b} <= (1-b)^n`.

Equivalently, at confidence `1-delta`, `p_>(M) <= 1-delta^(1/n)`. The inequality remains valid with discrete scores; continuity makes the bound exact. For `n=12` and `delta=0.05`, the upper bound is approximately `0.220922`. This is a repeated-calibration guarantee for a random selected threshold, not an ordinary binomial analysis of twelve independent trials at an already fixed gate. A maximum and sample size suffice to specify this counterfactual procedure; obtaining the individual counts would not by itself resolve its missing assumptions.

That result does **not** calibrate the source's inclusive rule. Its tail is `p_>=(M) = p_>(M) + P(S_new=M | M)`. The unknown point mass can be arbitrarily large: a population concentrated at 50 is compatible with the reported `n=12, M=50` and has inclusive pass probability 1, while its strict pass probability is 0. Thus no nontrivial distribution-free upper bound for the inclusive rule follows from that aggregate alone. With integer scores the hypothetical strict `N > 50` is equivalent to `N >= 51`; it is a different gate, not a correction to the source.

Further assumptions are also not established by the source. Its description of independent sequencing runs does not establish identical blank-score distributions or a prospectively fixed calibration sample size. Methods s4_6 says the separate upstream filter of at least 50 **reads per UMI family** was based on negative-control background. The source does not establish that this score-defining choice was fixed independently of the twelve calibration blanks; this is a limitation of what can be inferred, not evidence of an author error. An independently trained score can be conditioned upon in the theorem, but arbitrary adaptation of the score using the same calibration sample is not covered. Finally, workflow water blanks are not independently established native true-Other biological units. No numerical native false-entry bound, beta, target fraction, or biological conclusion is admitted here.

The classical context is Wilks (1941), *Determination of Sample Sizes for Setting Tolerance Limits*, Annals of Mathematical Statistics 12(1):91–96, [doi:10.1214/aoms/1177731788](https://doi.org/10.1214/aoms/1177731788); bibliographic metadata was checked, not the original full text. The directly inspected modern statement is Tong, Feng and Li (2018), *Neyman-Pearson classification algorithms and NP receiver operating characteristics*, Science Advances 4(2):eaao1659, [Proposition 1 and Equation (1)](https://pmc.ncbi.nlm.nih.gov/articles/PMC5804623/). It uses a strict score comparison, a class-0 calibration sample independent of score training, and an order-statistic binomial-tail bound, tight for continuous scores. Its Discussion explicitly requires iid observations within each class. Setting its order index to `k=n` yields the displayed maximum rule. This is an application of an established result, not a new theorem.

Suggested short addition to the prior audit:

> This fixed-gate limitation does not make all threshold reuse uninformative. For a fixed score pipeline, a prespecified number of iid controls can select a maximum threshold and support a classical one-sided tolerance bound for a future strict-above-maximum rule. That selection-aware result does not calibrate the source's inclusive count rule: integer-score ties add unknown mass at the threshold. The source also does not establish the required independence of score construction from calibration, iid target-matched controls, or a native true-Other denominator. Numerical native calibration remains unset.
