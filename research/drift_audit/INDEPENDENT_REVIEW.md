# Independent review of the small public drift audit

This is an internal computational and source-methods review by a separate agent, not external peer review. It uses retained local inputs from the `Genetics` release at commit `c1b47a977a9307281917ac1dee29861a813a7fd2`. The reviewer made no network requests and did not execute upstream analysis code or modify the TMD repository.

`python verify_review.py` independently parses the raw CSVs without importing the audit implementation. It verifies API response and reused-evidence hashes, SHA-256 and Git blob identities for all 19 selected inputs, their membership in the complete pinned tree, release/tag/commit linkage, culture and timepoint keys, and numerical fields in the four derived aggregate outputs, including batch/day coverage. The verification passed. The tree has 3,777 entries and is not truncated.

The independent totals are 33 clone labels (one ancestor and 32 evolved clones), 67 culture time courses, 336 sequencing metadata rows (335 days 0–4 and one ancestor pre-assay day −1), 268 nonblank CFU rows, and 474 measured plates. Four empty formatting rows in E5 are excluded. All observed CFUs are positive integers. There are 206 complete pairs, with mean `Q=(CFU1−CFU2)^2/(CFU1+CFU2)` of 4.937810075833765 and median 1.8328513591671487. No substantive computational discrepancy was found.

The interpretation needs the following qualifications:

- **Count units and plate exposure.** Pinned `HMM_stan.py` lines 23–24 describe raw CFUs as “not multiplied by dilution rate”; lines 45–49 model both plate counts with the same intended mean `Nb[t]*D[t]`, and lines 114–116 pass dilution separately. Manuscript paragraph P40 generally prescribes two independent technical replicates, each prepared by two 1:100 dilutions and plating 100 μL. This supports intended equal-exposure raw counts. The CSVs contain one dilution field per pair and do not verify the realized volume or dilution separately for each plate.
- **Meaning of the benchmark.** If independent raw counts have equal Poisson means, their first count conditional on positive total `n` is `Binomial(n,1/2)`, giving `E[Q|n]=1`. For unequal means, with `p=λ1/(λ1+λ2)`, the expectation is `1+(n−1)(2p−1)^2`; unequal exposure can therefore raise the statistic without non-Poisson biological variation. Multiplying counts by a common density scale multiplies Q by that scale. The current files are raw counts, so no density conversion should be applied.
- **Missingness.** Every CFU1 is present; 62 CFU2 measurements are absent. By batch, the missing counts are E1 4/4, E23 8/76, E4 4/64, E5 20/60, and E6 26/64. All 15 E5 day-0 pairs and all 16 E6 day-2 pairs lack their second plate. The manuscript P68 mentions, for example, contamination as a reason for absent plates, but does not identify the cause of each omission. Complete pairs are unevenly represented by batch and day. The receipt preserves missing counts by batch and day.
- **Dependence and genealogy.** Both evolved population histories derive from the LTEE ancestor. The 32 evolved clones are sampled at multiple timepoints within Ara+2 and Ara−2; Ara−2 includes S/L lineages. Biological culture replicates on different dates repeat the assay for a clone. These are 67 culture time courses and two sampled evolutionary population histories, not 67 independently evolved backgrounds. Multiple days within a course and pairs within a batch cannot automatically be treated as independent population-level replicates. Differences between population-label aggregates may also reflect batch composition and missingness.
- **Measurement noise and genetic drift.** Q is a descriptive technical-pair disagreement screen. It is not an estimate of descendant-number variance, an independently validated mutant-establishment effect, an unbiased estimator of the manuscript's CFU overdispersion, or validation of its posterior fit. In the pinned Stan code, `eta_cfus` is the excess over Poisson and `variance/mean=1+eta_cfus`; the manuscript's η_CFUs denotes the full ratio. The review supports keeping this measurement-noise issue separate from biological drift and establishment claims. No p-value or confidence interval treating all 206 pairs as independent is warranted here.
- **Eligibility.** The retained data contain no independently introduced singleton mutants with route-specific success/failure outcomes, known recovery-trial denominators, or matched Wsp/Aws/Mws selected outcomes. No WAM or recovery ledger is admitted. Raw reads, trajectories, posterior samples, and the full inference pipeline were outside this audit.
- **Provenance and licensing.** The retained API metadata links `Genetics` to the pinned commit and tree. Main at inspection is a later commit whose message says “Update README.md”; the release is the reproducible source. GitHub reports no license and the complete release tree contains no license/copying file. Retained Zenodo metadata is version record **21431098** (concept record 21431096), version `Genetics`, linked to that GitHub tag and labeled CC-BY-4.0. Its roughly 1.49 GB archive was not downloaded or hash-linked to these blobs. Attribute the source and distinguish that release-license evidence from a blanket license assertion about every accessible GitHub file. The audit's choice to keep third-party raw inputs ignored is conservative.
