# The two Levy count tables and their later technical measurements

Levy et al. supplied separate count tables for the first population (Source Data for Figure 1, MOESM90) and the second (Source Data for Extended Data Figure 2, MOESM93). They begin with a measured generation-zero pool. Counts refer to descendants carrying previously assigned labels. The files identify rows by position, contain no sequence identities, and give different scheduled visit grids. The complete baseline columns are identical row for row. Scoring within each population does not require linking individuals across them. Because multiple cells can descend from the same label, or carry later changes, a row is not a new mutation birth. [Paper](https://doi.org/10.1038/nature14279) · [E1 source CSV](https://static-content.springer.com/esm/art%3A10.1038%2Fnature14279/MediaObjects/41586_2015_BFnature14279_MOESM90_ESM.csv) · [E2 source CSV](https://static-content.springer.com/esm/art%3A10.1038%2Fnature14279/MediaObjects/41586_2015_BFnature14279_MOESM93_ESM.csv)

The authors describe using pooled reads to discover their barcode catalogue. Freezing a rule before scoring these existing records cannot restore a catalogue discovered using only the forecast-date reads. The denominator for the scores is the traced populations, with one measured endpoint per archive window. A later data release resolves technical replicate columns within the same experiments and extends their visit windows. Its five baseline columns describe multiple measurements of the starting material. Their sum yields zero at 3,145 positions for which the 2015 figures report one. All other overlapping counts agree after the technical columns are summed. This comparison describes the numbers in the two deposits; its outcome alone does not explain the reason for the discrepancy. [Later article](https://doi.org/10.1038/s41559-018-0758-1) · [E1 technical count CSV](https://static-content.springer.com/esm/art%3A10.1038%2Fs41559-018-0758-1/MediaObjects/41559_2018_758_MOESM3_ESM.csv) · [E2 technical count CSV](https://static-content.springer.com/esm/art%3A10.1038%2Fs41559-018-0758-1/MediaObjects/41559_2018_758_MOESM4_ESM.csv)

Download the four CSV files from the links above and pass them in E1/E2 order to the two scorers. They verify the original byte checksums and operate directly on the numeric rows.
