# A read-count forecast on the Stanford copy of the Levy yeast time series

The Stanford Good Lab course archive supplies 494,066 anonymous barcode rows and 12 assigned read counts per row. Its assignment identifies the data as one experiment from Levy et al. (2015). The course file has generations 0, 16, 32, 40, 48, 64, 72, 80, 88, 96, 104 and 112. The paper describes two replicates followed for about 168 generations with a common library and 48 generations of shared growth before the split. A barcode can be inherited by many cells and can be present before their split. A later leading barcode establishes the largest sampled share in its population. Its mutation history remains unobserved. The package gives no row crosswalk, replicate label or upstream inclusion filter in the table header. The course adds explicit numerical IDs. As checked below, each is its one-based data-row position in the original E1 source. Assigned depth sums the supplied rows at each visit. Treating them as all possible cells, genetic variants or independently evolving populations would enlarge the denominator beyond what the data support.

The competing forecast rules use generation 0 and generation 16. Both maximum early share and maximum `2 × early share − baseline share` uniquely choose barcode 262. This one-step linear score uses the two observations directly, irrespective of the remaining 96 generations. Generation 112 is the last column of this course table. Barcode 262 ranks exactly 91st there with 52,098 assigned reads. Barcode 3730 leads with 2,207,149 reads, followed by 901,830 for barcode 1488. Moving 652,660 reads from the leader to the runner-up would suffice to reverse that lead. Barcode 3730 had 272 reads at baseline, corresponding to tied ranks 277,382 through 277,962, and 288 at generation 16, tied ranks 93,224 through 93,759. Rows positive at the three visits numbered 494,066, 483,996 and 440,428. All rows entered the endpoint ranking. Code and exact score denominators appear in the accompanying `stanford_forecast.py` and `stanford_forecast.json`.

The course header omits the replicate label. Direct comparison with the original publisher E1 table matched all 494,066 rows and all 5,928,792 integer counts (12 per row). Each course identifier equals the one-based index among nonempty E1 data rows. The original E1 CSV contains 19,348,822 bytes and has SHA-256 `efc94566ce880bbfe8afda85c8643ca829a3124270632125689a819098bbb04d`. `compare_stanford.py` validates both row streams, headers, lengths and row indexing, and `stanford_match.json` records the result. The course table supplies independent distribution of the same E1 observations. The original 2015 supplement describes using reads pooled over both experiments and all visits to construct a catalogue of 487,922 tag clusters. The course file has 6,144 more rows, so the original cluster total alone cannot identify this table's row construction. A frozen scoring rule applied to a retrospectively constructed barcode catalogue yields an archival hindcast. The reported accuracy pertains to that catalogue.
